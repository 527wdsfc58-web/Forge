Forge V0.21
GitHub Pages deployment package.
Keep index.html at the root of the selected Pages source.

V0.21 content release:
- Adds 100 new non-mobility workouts: 25 Strength, 20 AMRAP, 15 EMOM, 30 Conditioning/Circuit and 10 Run.
- Adds simple soccer-oriented exercises: Shuttle Run, 10m Sprint, Lateral Shuffle and Skater Hops.
- Automatically creates a 3-month training plan starting on the next Monday after installation/update.
- Four main workouts are scheduled Monday, Tuesday, Thursday and Friday, with existing Forge mobility workouts scheduled Wednesday, Saturday and Sunday.
- Plan emphasis: fat loss, general conditioning, lower-body strength, single-leg strength, aerobic fitness, repeated-sprint ability and change of direction relevant to soccer.
- No new mobility workouts were added.

The AI Workout Generator remains available in the UI but is not required by this release and no API key is stored in the browser.
